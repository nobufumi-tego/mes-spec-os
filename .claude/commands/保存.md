---
description: 現在の作業状態をローカル Git に保存する
---

以下を実行してください：

1. `git status` で変更内容を確認
2. ユーザーに「保存する内容のサマリ」を日本語で表示
3. 機密混入チェック（1 つでも該当したら警告して中断）：
   - `inputs/` 配下のファイルが含まれていないこと
   - `reference/ENAA/` 配下のファイル本体（README.md 以外）が含まれていないこと
   - ステージ対象の `outputs/` ファイルに顧客名・取引先名らしき固有名詞が含まれる場合、リモート設定（`git remote -v`）があれば注意喚起（本スターターはローカル運用前提）
4. `git add` で対象ファイルをステージ（上記除外を守る）
5. コミットメッセージは Claude が日本語で生成（例: "MES仕様書: マルヨシ精工 - Stage 2 要求機能まで記録"）
6. `git commit` を実行
7. 結果を一行で報告

`git push` はしない（本スターターはローカル運用前提。利用者が明示的に求めた場合のみ、公開リスクを確認した上で判断を仰ぐ）。
